# Design System

## Palette

Use one restrained light-theme palette across the full PDF.

| Token | Value | Use |
| --- | --- | --- |
| page | `#f6f4ef` | page background |
| surface | `#ffffff` | cards, tables, callouts |
| ink | `#1f2937` | headings and body text |
| ink-muted | `#5b6472` | secondary text |
| line | `#d9dee7` | dividers and table borders |
| accent | `#6c8fa3` | links, small highlights, chart anchor tone |
| accent-soft | `#dbe7ee` | summary fills and subtle highlights |
| success-soft | `#dfeee7` | positive callouts |
| warning-soft | `#f4ead8` | caution callouts |
| danger-soft | `#f2dfdf` | risk callouts |

## Typography

- Use one sans-serif family unless the project already has a strong editorial pairing.
- Keep body text dark and plain.
- Let spacing and hierarchy carry the design instead of decoration.

Suggested scale:

| Element | Size | Weight | Notes |
| --- | --- | --- | --- |
| cover title | `30-38px` | `700` | compact line height |
| section title | `20-24px` | `600` | stable anchor target |
| subsection | `15-18px` | `600` | keep dense and readable |
| body | `11-12.5pt` | `400` | `1.5-1.7` line height |
| caption | `9-10pt` | `400` | muted |
| footer | `8.5-9pt` | `500` | concise |

## Layout

- Keep generous page margins.
- Prefer full-width narrative flow with occasional inset summary blocks.
- Use whitespace before section dividers instead of oversized graphic elements.
- Keep each section visually calm and easy to scan.

Suggested spacing rhythm:

- `8px` micro gaps
- `16px` inner spacing
- `24px` block spacing
- `40px` section spacing

## Tables

- Use white or near-white table surfaces on the light page.
- Use thin borders and soft zebra striping only when needed.
- Right-align numeric columns.
- Keep headers slightly darker or bolder, not heavily colored.
- Split very wide tables or move overflow content to the appendix.

## Charts

Use a single palette throughout the report:

1. `#6c8fa3`
2. `#7da6a1`
3. `#b89b74`
4. `#a98997`
5. `#9fa7b3`

Rules:

- Prefer bars, lines, and ranked comparisons over decorative visualizations.
- Label directly where possible.
- Keep gridlines faint.
- Put the takeaway above or below the chart in one sentence.

## Branding

- Keep the logo crisp and comfortably sized.
- Use the brand name in the footer even when the logo appears only once.
- Use accent color for restraint, not saturation.

## Accessibility-Oriented Quality

- Keep contrast strong between text and background.
- Avoid tiny captions or dense tables that will degrade in print.
- Do not rely on color alone to carry meaning.
