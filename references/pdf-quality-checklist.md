# PDF Quality Checklist

## Navigation

- The table of contents exists and matches the final section order.
- TOC links work when the renderer supports internal links.
- Heading hierarchy is stable enough for clean bookmarks.
- Bookmark output has been checked in the exported PDF, not assumed.

## Branding

- The logo or brand image is crisp.
- The brand name appears consistently in the footer.
- Accent colors stay restrained and consistent.

## Layout

- Page margins are consistent.
- Page numbers appear in the intended position.
- Section starts are visually clear.
- Tables and figures do not collide with the footer.
- Long tables are split or moved to the appendix when needed.

## Content

- Executive summary is concise and useful.
- Charts only appear when the source data supports them.
- Chart labels are readable and meaningful.
- Tables remain legible in print and PDF zoomed-out views.
- Captions explain what the reader should notice.

## Output Integrity

- PDF metadata is populated when the stack supports it.
- Images are high enough resolution for print and screen.
- File size is reasonable for sharing.
- Exported pages were reviewed manually before delivery.

## Final Question

Would an enterprise stakeholder trust this PDF after skimming three pages? If not, improve clarity before delivery.
