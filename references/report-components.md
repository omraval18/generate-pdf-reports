# Report Components

## Core Components

### Cover Page

Include:

- report title
- optional subtitle
- brand logo or image
- date
- author or team
- one-sentence positioning summary

Keep the cover clean and spacious.

### Table of Contents

Include:

- top-level sections
- optional subsection entries for long reports
- internal links where the renderer supports them

The visible TOC is not enough by itself. Keep heading IDs stable so the PDF can map links and bookmarks cleanly.

### Executive Summary

Use for:

- top findings
- business implications
- prioritized recommendations

Keep it short enough to scan on one page when possible.

### KPI or Summary Blocks

Use when:

- a few metrics explain the report quickly
- comparisons or headline numbers matter

Do not turn every data point into a card.

### Narrative Section

Standard shape:

1. section title
2. short framing paragraph
3. supporting evidence
4. table or chart if needed
5. takeaway or recommendation

### Table Block

Use for:

- audit findings
- rankings
- category comparisons
- entity inventories

Prefer tables over charts when precision matters more than pattern recognition.

### Chart Block

Use only when structured numeric data exists.

Best fits:

- trends over time
- before/after comparisons
- ranked categories
- channel shares

Avoid pie-heavy or ornamental chart choices.

### Insight Callout

Use for:

- key risk
- opportunity
- notable anomaly
- action recommendation

Keep callouts brief and evidence-linked.

### Image or Logo Block

Use for:

- brand placement
- screenshots
- visual evidence
- illustrative diagrams

Keep captions concise and relevant.

### Appendix

Use for:

- raw exports
- methodology
- long inventories
- supplemental tables

Keep the main narrative readable by moving detail here.

### Footer

Repeat:

- brand name
- optional confidentiality label
- page number

Keep the footer subtle and consistent.
