Use `report.html` as the default starter shell when the project does not already have a stronger branded template.

Replace the `{{...}}` placeholders with project-specific data or adapt them into the repository's template system.

Keep section IDs stable so the visible contents page and exported PDF bookmarks stay aligned.

Use `styles.css` as a token source and layout baseline, not a final locked visual system.

If the chosen renderer cannot support repeated footers or page counters exactly as written, preserve the brand footer and page numbering with the renderer's native mechanism.
